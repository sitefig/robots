Controlla quali crawler lascia entrare il tuo robots.txt

Inserisci un sito. sus.bot scarica il suo robots.txt e mostra quali pagine può visitare ogni motore di ricerca e ogni crawler di IA. Elenca anche i percorsi che il file rivela a chiunque lo legga. Il controllo avviene nel tuo browser ed è gratuito.

Recuperiamo /robots.txt dall'origine del sito. Percorsi e stringhe di query vengono ignorati.

Accesso dei crawler

Risolto per crawler secondo la RFC 9309: vince il gruppo più specifico, poi la regola più lunga, e a parità Allow.

Prova un percorso

Verifica qualsiasi percorso o URL con qualsiasi user-agent.

Accesso reale per user-agent

Richiede di nuovo il file tramite il proxy con la vera stringa user-agent di ogni crawler. Uno stato o un contenuto diverso significa che il server tratta quel crawler in modo diverso (blocco dei bot, regole WAF, cloaking).

Problemi

Note di sicurezza

Regole Disallow che puntano ai luoghi in cui gli attaccanti guardano per primi. Viene controllato ciò che il file rivela, non se i percorsi esistono o sono protetti.

Scopri quando un rilascio cambia il tuo robots.txt

Il monitoraggio ripete questi controlli e ti avvisa quando nel file compare un percorso sensibile o un errore di sintassi.

Cosa un estraneo scopre su questo sito dal solo file: la piattaforma usata, i bucket cloud, altri nomi host, punti di ingresso delle API, feed di dati, tipi di file e note lasciate nei commenti. Nulla viene scaricato o sondato; tutto viene letto direttamente dal testo.
