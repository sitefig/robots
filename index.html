Check which crawlers your robots.txt lets in

Enter a website. sus.bot fetches its robots.txt and shows which pages each search engine and AI crawler may visit. It also lists the paths the file reveals to anyone who reads it. The check runs in your browser and is free.

We fetch /robots.txt from the site's origin. Paths and query strings are ignored.

Crawler access

Resolved per crawler with RFC 9309 matching: the most specific group wins, then the longest rule, and ties go to Allow.

Test a path

Check any path or URL against any user-agent.

Real access by user-agent

Request the file again through the proxy with each crawler's real user-agent string. A different status or body means the server treats that crawler differently (bot blocking, WAF rules, cloaking).

Security notes

Disallow rules that point at places attackers look for first. This checks what the file reveals, not whether the paths exist or are protected.
